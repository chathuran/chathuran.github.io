01 / CONTEXT

The delivery challenge

An AWS-hosted property management platform needed ongoing application development, deployment, and production support for Australian customers.

02 / OWNERSHIP

My contribution

I developed Java Spring Boot services and REST APIs, built Vue.js frontend functionality, and integrated interfaces with backend services. I also built and maintained CI/CD workflows using GitHub Actions and AWS deployment services.

03 / IMPLEMENTATION

The approach

The workflows connected GitHub Actions with AWS deployment services to automate application delivery. My work also included optimising MySQL queries and schemas, managing AWS infrastructure configurations and deployments, and troubleshooting production issues to maintain reliability and availability.

04 / RESULT

The outcome

Delivered an automated deployment pipeline as part of maintaining the AWS-hosted platform. The contribution spans application development, cloud delivery, and production troubleshooting.
