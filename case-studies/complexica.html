01 / CONTEXT

The engineering challenge

The enterprise analytics platform relied on backend services, database queries, and batch processing. Improving backend performance meant working on the data-processing paths behind the application.

02 / OWNERSHIP

My contribution

I implemented and maintained Spring Boot microservices and REST APIs, then tuned database queries and batch processes. I worked within an Agile team alongside business analysts, QA, and data scientists.

03 / IMPLEMENTATION

The approach

The performance work focused on query optimisation and batch-process tuning. Alongside application development, I implemented AWS CodeBuild and CodePipeline pipelines and supported production releases, monitoring, and incident resolution.

04 / RESULT

The outcome

The query and batch tuning improved backend performance by 50%, as recorded in my résumé. This case highlights the performance work; the role also included delivery automation and production support.
